# Calculator Frontend
This is frontend of front-back separated calculator system.
## Tech Stack
HTML, CSS, JavaScript
## Runtime
Any browser
## How to run
1. Clone repo
2. Open calculator.html directly in browser
## Backend connection
Modify API_BASE variable in js file to your backend url.
## Function
- Calculator UI and button interaction
- Send expression to backend API
- Show calculation result and error message
- Fetch history records
- Delete single history
## Deploy
Deploy static files on GitHub Pages.
