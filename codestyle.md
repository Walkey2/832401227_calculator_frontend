# Frontend Code Style Guide
Reference standard: Google JavaScript Style Guide
1. Use 2 spaces for indentation, no tabs.
2. Use camelCase for variables, UPPER_SNAKE_CASE for constants.
3. Use const / let, avoid var.
4. Split code into modules: UI rendering and network requests separated.
5. Use semantic naming, avoid meaningless single-letter variable names.
6. Catch exceptions for asynchronous fetch requests.
7. Use semantic HTML tags; kebab-case for CSS class names.
8. Add inline comments to explain complex logic.
9. Do not submit redundant console.log to repositories.
